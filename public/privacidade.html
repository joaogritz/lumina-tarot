Privacidade

Última atualização: 3 de novembro de 2026

O Lumina Tarot é um projeto pessoal e de código aberto. Ele não tem contas, não usa cookies de rastreamento e não tem ferramentas de análise ou anúncios. Esta página explica quais dados passam pelo site, para onde vão e como controlá-los.

Esses dados não são enviados a nenhum servidor e não são criptografados. Quem usa o mesmo navegador pode vê-los. Limpar os dados do site apaga tudo; para guardar o diário, use Exportar no Diário.

O que é enviado na interpretação online

Com a opção Interpretação online com IA ligada (o padrão), ao pedir uma interpretação o site envia:

  • a pergunta que você digitou, se houver;
  • as cartas sorteadas, com posição, orientação e significados;
  • o nome e as posições da tiragem.

Esses dados vão primeiro ao nosso servidor de interpretação, hospedado na Cloudflare (Cloudflare Workers), que os repassa à API Gemini do Google para gerar o texto. O servidor não grava a pergunta nem a resposta. A Cloudflare e o Google processam os dados conforme as próprias políticas; dependendo do plano da API, o Google pode reter o conteúdo e usá-lo para melhorar os seus serviços.

Evite incluir nomes completos, documentos, endereços ou detalhes de saúde nas perguntas.

Para não enviar nada, desmarque a opção logo abaixo do campo de pergunta. No modo local, a interpretação é montada no próprio aparelho, a partir dos significados das cartas.

Hospedagem

O site é servido pelo GitHub Pages. Como qualquer servidor web, o GitHub registra dados técnicos de acesso, como o endereço IP, para operar e proteger o serviço. As fontes e as imagens das cartas são servidas pelo próprio site, sem chamadas a terceiros.

Sobre as leituras

As leituras são reflexões simbólicas, não previsões. Elas não substituem orientação médica, psicológica, jurídica ou financeira. Se você estiver em sofrimento ou pensando em se machucar, procure alguém de confiança ou o CVV pelo telefone 188; em perigo imediato, ligue 192 (SAMU) ou 190.

Seus direitos

Como o projeto não mantém dados pessoais em servidores próprios, você controla os dados guardados no aparelho: pode exportá-los, apagá-los no Diário ou limpar os dados do site no navegador. Para dúvidas sobre esta política, abra uma issue no repositório do projeto.
